# Погодный дайджест

Консольная утилита на Node.js для получения прогноза погоды по одному или
нескольким городам через открытый REST API [Open-Meteo](https://open-meteo.com/)
(ключ доступа не требуется).

## Требования

- Node.js версии 18 или выше (используется встроенный `fetch`).

## Установка

```bash
git clone <ссылка-на-репозиторий>
cd weather-digest
```

Внешние зависимости не используются, `npm install` не требуется.

## Запуск

```bash
node src/index.js --city "Нижний Новгород" --days 3
```

Несколько городов через запятую:

```bash
node src/index.js --city "Москва, Санкт-Петербург, Казань" --days 5
```

### Параметры

| Параметр  | Обязательный | Описание                                              |
|-----------|--------------|--------------------------------------------------------|
| `--city`  | да           | Название города или список городов через запятую       |
| `--days`  | нет          | Количество дней прогноза, 1–7. По умолчанию — 3         |

## Как это работает

1. Для каждого города выполняется запрос геокодинга — получение координат
   по названию (`geocoding-api.open-meteo.com`).
2. По полученным координатам выполняется запрос прогноза погоды
   (`api.open-meteo.com`).
3. Города обрабатываются **параллельно** (`Promise.allSettled`) — ошибка по
   одному городу не прерывает обработку остальных.
4. В консоль выводится: название города, страна, координаты и таблица
   по дням (дата, мин./макс. температура, суммарные осадки).
5. Отчёт по каждому успешно обработанному городу сохраняется в файл
   `reports/{город}-{ГГГГ-ММ-ДД}.json`.

## Обработка ошибок

Утилита корректно обрабатывает и сообщает понятную причину при:

- отсутствии обязательного параметра `--city`;
- некорректном значении `--days` (не число или вне диапазона 1–7);
- неизвестном названии города (геокодинг не нашёл совпадений);
- недоступности сети (таймаут, обрыв соединения);
- ошибке на стороне API (не-2xx HTTP-статус, некорректный JSON).

Код завершения процесса (`exit code`) отличен от нуля, если аргументы
некорректны или ни один город не удалось обработать успешно.

## Пример вывода

```
Город: Нижний Новгород, Россия
Координаты: 56.3269, 44.0059

Дата        Мин, °C  Макс, °C  Осадки, мм
----------  -------  --------  ----------
2026-09-13  10.2     18.4      0.0
2026-09-14  9.8      17.1      1.2
2026-09-15  11.0     19.3      0.0

Отчёт сохранён: reports/Нижний_Новгород-2026-09-13.json

Готово: 1 из 1 город(ов) обработано успешно.
```

## Структура проекта

```
weather-digest/
├── src/
│   ├── index.js    # точка входа, разбор аргументов, оркестрация
│   ├── api.js      # запросы к Open-Meteo (геокодинг + прогноз)
│   ├── report.js   # вывод в консоль и сохранение JSON-отчёта
│   └── utils.js    # парсинг/валидация аргументов, ошибки, хелперы
├── reports/        # сюда сохраняются JSON-отчёты (создаётся автоматически)
├── package.json
└── README.md
```
